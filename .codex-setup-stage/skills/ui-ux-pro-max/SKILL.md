# UI UX Pro Max para Codex

Fonte: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

## Fluxo

- Priorize acessibilidade, interação, desempenho, responsividade, consistência, tipografia e feedback.
- Considere mobile-first quando o problema for responsivo.
- Consulte `references/quick-reference.md` e `references/pro-rules.md` somente quando necessário.
- Para pesquisa local, execute `python3 scripts/search.py "<consulta>" --domain <domínio>` a partir desta pasta da skill.
- Valide a interface visualmente quando houver navegador disponível.

Não carregue toda a base de design no contexto. Pesquise apenas o domínio relevante.
